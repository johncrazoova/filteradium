# فیلترادیوم - Filteradium
## پلتفرم فیلترنویسی هوشمند بورس ایران

### 🎯 هدف
ساده‌سازی فیلترنویسی و تحلیل سهام بورس اوراق بهادار تهران برای معامله‌گران.

### 📊 ویژگی‌های MVP
1. فیلترنویسی ساده (Drag & Drop)
2. ۱۰ فیلتر آماده
3. داشبورد لحظه‌ای
4. هشدار تلگرام

### 🛠️ استک فنی
- Frontend: HTML/CSS/JS (بدون فریمورک سنگین)
- Backend: Node.js + Express
- Database: SQLite (اولیه) → PostgreSQL
- Scraper: Puppeteer
- هشدار: Telegram Bot API

### 📅 نقشه راه
- هفته ۱-۲: طراحی UI و ساختار پایه
- هفته ۳-۴: فیلترنویسی و اتصال به دیتا
- هفته ۵-۶: داشبورد لحظه‌ای
- هفته ۷-۸: هشدار و پرداخت
